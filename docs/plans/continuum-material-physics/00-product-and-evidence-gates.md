# Package 00 — Shared product and evidence gates

## Outcome

Require a bounded player/tool consumer and falsifiable evidence contract before
any continuum solver implementation. Package 00 defines shared form, not a
shared numerical particle schema.

Every lane must freeze:

- one representative scenario and exact non-goals;
- owner, canonical future-affecting fields and reconstructible caches;
- units, cadence, material/profile constants and hard capacities;
- canonical order, reduction, quantization and failure semantics;
- scenario geometry/horizon/input trace and reference-data hashes;
- metric formulas, populations, aggregation and thresholds before execution;
- target hardware/build and whether performance is gate or report-only;
- exact active save/restart compare point and pre-activation fallback;
- the ProductCheck name and evidence artifact boundary.

Missing values are explicit blockers. An implementer cannot select a
constitutive constant, tolerance, resolution, fallback or authority model from
ambient defaults after code begins.

## Shared owner boundary

Physical Embodiment is the future owner of active continuum regions. Each
material lane owns only its material-specific state and emits a bounded stable
reaction/flux proposal at a declared composite commit point. PhysX remains the
only writer of rigid/articulation state. Renderer, GPU, neighbor/grid and
surface caches are reconstructible.

## Evidence discipline

- correctness thresholds are frozen before the run and cannot be widened
  after failure;
- driven/open scenarios account for external impulse, energy and material
  flux instead of claiming naive conservation;
- reference curves name source, exact extraction/normalization and hash;
- external solver output is independent aggregate evidence, not copied
  implementation code or exact trajectory identity;
- exact/replay comparisons use canonical bytes/roots; tolerance is diagnostic
  only for explicitly classified external/numerical metrics;
- heavy/generated artifacts remain outside Git; checked-in fixtures are small
  bounded inputs, hashes and summaries.

## Failure semantics

Nonfinite state, invalid profile/content, capacity/iteration excess,
non-convergence, stale identity/revision, result collision, conservation
violation or downstream owner rejection aborts the complete candidate. Lab
tools stop at the first fault. Production retains the previous complete
generation and cannot advance another physical owner independently.

## Exit

A lane-specific Package 10/W0 may start only when its consumer and evidence
table instantiate every requirement above. Package 00 by itself proves no
physics and creates no public contract.

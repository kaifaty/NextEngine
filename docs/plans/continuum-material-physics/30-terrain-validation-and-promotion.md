# Package 30T — Terrain validation and production promotion

## Outcome

Promote only the smallest terrain consumer whose preceding packages pass.
Dry-sand contact, saturation and free-water flux are independently promotable;
later packages do not retroactively validate earlier ones.

## Dry-sand promotion minimum

- Package 10T exact profile/corpus closure;
- Package 11T reference conservation, curves and exact same-target roots;
- Package 12T prescribed single-wheel curves and exclusive MPM contact pair;
- Package 13T exact active save/restart;
- target performance for the declared patch and current integrated ceilings;
- production command/content path, authored rigid-terrain pre-activation
  fallback and identical `game`/headless behavior;
- Windows/Linux canonical-root evidence on one exact revision.

Saturation requires 14T in addition. Free-water exchange requires water W5,
14T and 15T. Package 20X/21X are required only for a product profile that
actually sleeps or transfers modified regions.

## Promotion change

Create a consumer-backed Accepted ADR narrowing the current physics baseline
without moving rigid authority from PhysX. Update affected Physical
Embodiment, persistence, streaming, material, presentation, routing,
traceability and roadmap documents together. Add only exact material profiles,
owner states, reaction/flux records and read-only projections consumed by the
selected scenario.

## Stop conditions

Do not promote generic soil from one sand profile, a full vehicle from the
prescribed wheel, wet behavior from dry curves, or persistence from a mesh/rut
cache. Do not allow simultaneous PhysX and MPM ground contact, post-hoc curve
tolerance changes, partial owner commit, native/sidecar save authority,
renderer-fed collision or unbounded grid/sample allocation.

Failure retains accepted rigid terrain or the last separately promoted lower
material profile. It does not weaken the mandatory game or grant later package
status.

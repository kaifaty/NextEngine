2. High cancellation remains contained.
3. Nonzero coefficient/candidate radii are necessary; dropping either rejects
   exact containment.
4. Transposition changes profile and product roots.

6. Stale face, common, width, order, candidate-lane and candidate-state
   identities reject before dots.
7. Mutating one high/low/radius/root changes the artifact or product root.
8. Exact-oracle mutation changes containment but never the finite product.
9. Classifier precedence covers every route.
10. R63B--R63Y byte regressions pass. Candidate updates, PCG scalars,
    preconditioner solves, sparse builds and timing are zero.

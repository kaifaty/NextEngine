## Exact claim

Let the frozen R63ZH parent fixture provide dimension `n=102`, tangent width
`m=315`, binary128 tangent entries `T`, positive scale `sigma`, exported
binary64 upper factor and permutation, projected inverse scale/RHS, and the
reviewed R63Y affine verifier.

Define the frozen tangent-Gram producer operator exactly over the represented
dyadics:

```text
K_T[i,j] = sigma * sum(k=0..314) T[i,k] * T[j,k].
```

Construct one immutable width-two binary64 artifact whose center for every
ordered coefficient is the two-word projection of the frozen binary128
tangent-product materialization and whose outward radius contains the exact
dyadic `K_T[i,j]`. Consume only the deterministic centers in the unchanged
R63ZB two-update PCG recurrence with the exported factor as preconditioner and
the projected portable RHS/inverse scale.

The positive resolution requires all of the following:

1. all `10,404/10,404` exact tangent-Gram coefficients lie inside the frozen
   artifact intervals;
2. all three executed K2 operator products (`K_T*x0`, `K_T*p0`, `K_T*p1`)
   are independently enclosed row by row against exact dyadic tangent-Gram
   application;
3. recurrence arithmetic is complete, every required `r^Tz` and `p^TK_Tp`
   is strictly positive, and the exact frozen work ledger closes;
4. the unchanged R63Y verifier returns reject/reject/pass for `x0,x1,x2`,
   with state 2 exactly `24+/78-/0?` at sign root
   `89b2908b21369cf77a376287ed8142026827815c45a59aa70d2e831aac406094`;
5. the unchanged common K2 artifact remains a rejecting negative control, all
   identity/mutation/failure controls distinguish their injected defects, and
   R63ZG/R63ZH plus the parent cache remain byte exact.

The positive route is `TANGENT_GRAM_TWOFOLD_STATE2_CANDIDATE`.

## Exact negation

R63ZI resolves negatively when the frozen apparatus and controls are valid but
at least one required coefficient/product enclosure, recurrence arithmetic,
positivity condition or state-2 verifier clause fails. The first failing
ordered coefficient, product site, row, state or scalar is retained.

A negative result is bounded to this one artifact and arithmetic profile. It
does not refute PCG, the exported factor, a dynamic tangent builder, another
portable expansion width or continuum physics.

## Fixed definitions and model

- Units and nondimensionalization: inherited unchanged from R63X/R63Y/R63ZH;
  R63ZI adds no physical quantity.
- Coordinate frame and signs: inherited row order; operator product is
  positive `K_T*x`; residual is `rhs-K_T*x`; all PCG update signs remain the
  frozen R63ZB signs.
- Domain: one non-empty frozen dimension-102 exported lane and exactly three
  sealed states.
- Arithmetic model: exact canonical dyadics for the oracle; binary128 only for

- Boundary conditions/topology: immutable R63ZH fixture, tangent root, factor,
  permutation, RHS/scale, verifier profile and recurrence order.
- Architecture facts: this remains an offline C++ research tool. No public
  contract, runtime owner, persistence schema, GPU authority or production
  state changes.

## Resolution and near-miss firewall

- Counts as positive: only all five positive clauses plus two byte-identical
  Release outputs and fresh independent review `GO`.
- Counts as negative: a valid apparatus reaches a named frozen rejection with
  first-boundary evidence.
- Does not count: binary128-only recurrence, common K2 operator, verifier-fed
  candidate value, exact-oracle sign, fitted epsilon/radius, omitted state,
  changed factor/RHS/scale, additional iteration, hidden residual replacement,
  successful build alone or author-only `PASS`.
- Claim ceiling after success: one offline fixed-profile operator/recurrence
  candidate. A dynamic builder, corpus, runtime stopping, Rust integration,
  deterministic execution profile, ProductChecks, timing and production
  promotion remain open.

## Evidence plan and fixed work

- Build the tangent matrix through exactly `102` frozen binary128 basis
  products: `42,534` Dot2 reductions, `6,554,520` terms and `10,404` scale
  products. This is offline builder work, not runtime credit.
- Independently form the symmetric exact dyadic tangent Gram using `5,253`
  upper-triangle dots and `1,654,695` exact products, mirror `5,151` entries,
  project `10,404` centers and verify `10,404` containments.
- Execute exactly three operator products, three factor solves, two rho dots,
  two denominator dots, three scalar divisions, 204 solution updates, 204
  residual updates, 102 direction updates and three certificates.
- Independently audit `3*102` product rows against exact tangent-Gram values;
  no candidate center, verifier image or common-operator value enters the
  exact reference.
- Keep the common K2 artifact as a complete negative recurrence control, plus
  stale/unsealed/resealed artifact, dropped-low, radius, nonfinite, dimension,
  source-root, result-sealing and classifier-precedence controls.
- Freeze source/diff/command/binary/stdout hashes before a fresh reviewer sees
  the candidate. Permit one initial review and, only if needed, one batched
  repair plus one re-review.

## Stop and reconsider

- Stop with `INCONCLUSIVE` on apparatus failure, unavailable frozen inputs,
  mismatched parent hashes or a load-bearing finding that survives the one
  permitted repair/re-review.
- Do not retry with more iterations, a fitted tolerance, common-operator
  correction, adaptive precision, native binary128 runtime or a changed
  verifier.
- On reviewed positive resolution, freeze a successor dynamic builder that
  derives the same tangent-Gram K2 artifact from runtime binary64 tangent
  storage, then require broader active-set correspondence before integration.
- On bounded negative resolution, localize the first coefficient/product or
  recurrence boundary and choose the smallest representation change that
  preserves the same tangent-Gram equation.
- Production promotion still requires the SPEC-38/ADR-076/ADR-081 consumer,
  deterministic execution, corpus, persistence/coupling, platform and
  performance gates independently.

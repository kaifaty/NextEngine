## Claim and negation

Execute exactly the frozen recurrence from K2 start through two updates. The
finite producer receives no binary128/exact candidate, sign, expected scalar
or passing iteration. Seal all producer roots, then run the independent R63Y
twofold affine certificate on `x0,x1,x2`.

Positive resolution requires complete finite work, positive exact-K2 Krylov
scalars, immutable identity correspondence, state 0/1 rejection, state-2
`24+/78-/0?`, and the frozen sign root
`89b2908b21369cf77a376287ed8142026827815c45a59aa70d2e831aac406094`.

The negation is the first invalid parent/fixture/identity, K2 normalization,
factor solve, operator product, nonpositive rho/denominator, scalar division,
vector update, verifier, expected ladder or work/lifecycle boundary.

## Producer identity

Bind R63ZA semantic/stdout/identity/fixture, R63Z operator artifact, R63Y
profile root, exported factor/permutation, RHS, dimension, width, rounding and
the exact recurrence order. Each state binds solution/residual/direction,
operator/preconditioner products and rho/denominator/alpha/beta roots.

Any stale or mismatched artifact rejects before new recurrence work. Partial
states are private; no solver/world state is published.

## Arithmetic and independence

- Deterministic operands have radius zero and exact value `hi+lo`.
- Use R63ZA canonical K2 add/multiply/three-correction divide.
- Use fixed K2 dot accumulation for `rho` and denominator; require its exact
  twofold value to be positive without comparator input.
- Use the immutable R63Z K2 common block for all three products. Product
  containment radii are audit-only and cannot enter recurrence operands.
- Use the immutable exported factor for start, `r0` and `r1` solves. R63ZA
  dependency radii are audit-only and cannot enter recurrence operands.
- Build R63Y solution artifacts directly from sealed K2 words with zero
  solution radius. Exact/binary128 candidate vectors are comparator-only and
  absent from producer/verifier signatures.

## Controls

   independently solved reference.
2. Cancellation produces required nonzero low words.
3. Nonpositive rho and denominator reject before update publication.
4. Division, overflow, subnormal, NaN/Inf and normalization failures reject.
5. Replacing any R63Z product or R63ZA factor center by its audit radius is
   detected as a forbidden-role mutation.
6. Stale operator/factor/profile/RHS/lane/state/order identity rejects before
   recurrence work.
7. Mutating high, low, scalar or state roots rejects the transaction.
8. Comparator mutation never changes producer, verifier or route.
9. State 0/1 pass and state-2 reject negatives cover ladder precedence.
10. R63B--R63ZA regressions remain byte-exact.

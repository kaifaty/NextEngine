# VG — Optional GPU correspondence mirror

## Outcome

Measure a GPU implementation against the frozen V1 CPU authority without
placing GPU execution on the critical path or changing any gameplay, save,
topology or rigid-body result.

VG may start only after `VEGETATION-BEAM-REF-P1 = PASS`. It consumes exact
definitions, profiles, forcing and CPU corpus. Device/driver/shader/build,
dispatch/reduction and float-control identities are recorded. GPU buffers and
completion order are never owner state.

Compare aggregate node/section trajectories, modes, work/energy residuals,
failure classification and performance under thresholds frozen before the
first GPU run. Exact CPU roots remain authoritative; final GPU quantization
does not establish equivalent history.

`VEGETATION-MIRROR-P1` is report-only until a separately accepted authority
model exists. Failure or unavailable hardware leaves CPU behavior unchanged.
GPU source, large trajectories and captures remain outside Git.

# V6 — Forest LOD and performance

## Outcome

Add the explicit static/shader/modal/active/refined representation ladder and
prove the V0 production forest workload on THOTH without camera or wall-time
authority. V6 follows the destructible vertical and exact active persistence.

## Tier rules

```text
AuthoredStatic -> ShaderWind -> ModalStructural -> ActiveStructural -> RefinedSection
```

- `AuthoredStatic` and `ShaderWind` cannot produce physical interaction or a
  precise fracture outcome.
- `ModalStructural` stores exact bounded modal coordinates/velocities and binds
  the canonical basis/profile hash.
- `ActiveStructural` uses the V1 graph state.
- `RefinedSection` adds the V0 section lattice and cannot downgrade while cut,
  fracture or unstable support is pending.

Each adjacent transition is `Prepare -> Validate -> Commit -> Stabilize` and
has V0 pose, velocity, energy, damage/history and cycle-drift bounds. A request
uses only canonical residency/distance/importance/contact/damage facts, stable
ID and manifest integer tokens. Renderer camera/frustum/occlusion, measured
CPU/GPU time, cache warmth and worker completion are forbidden.

Unsupported precise interaction deterministically upgrades, defers or rejects
according to the fixed profile. It never fabricates a cut/fall from a lower
tier. Failed transition keeps the source tier and typed diagnostic.

## Workload and determinism

Run the exact V0 visible/static/shader/modal/active/refined counts, graph sizes,
cadences, command/contact trace and transition schedule under declared worker
modes and registration permutations. Canonical state/tier/outcome roots must
match; timing is evidence, never an input.

Record p50/p95/p99 CPU standalone stop-target cost, memory, transition latency,
active nodes/proxies/cells and exact roots. Apply the repository Performance V5
methodology and THOTH preflight. Stress profiles are report-only and cannot
replace the production gate.

Integrated promotion additionally passes the successor mutually exclusive
`world-dynamics-step` row covering every substep, merge, validation and
publication in one gameplay tick; standalone PASS values are not summed.

## Stop and exit

`VEGETATION-LOD-P1 = PASS` requires every adjacent transition/cycle and
camera/timing independence threshold. Conditional `performance` must pass the
V0 production budget. After two evidence-backed optimization cycles a miss
stops the program as `RESEARCH_ONLY`; the workload or budget cannot be changed
inside V6.

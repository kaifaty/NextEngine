# V5 — Exact active persistence

## Outcome

Save and restore complete active living-structure state in the same atomic
physical checkpoint closure as required PhysX state. Prove exact continuation
before introducing modal/sleep persistence or forest streaming.

## Required owner state

- exact definition/profile/topology/tier revisions and roots;
- ordered node pose/velocity and selected V1 strain/damage/history state;
- complete activated section-cell state and felling-zone mapping;
- root anchor and collision-proxy mapping;
- pending/terminal topology and PhysX handoff disposition;
- exact exchange sequence/root needed to reject duplicate continuation.

Factorizations, residual scratch, adjacency acceleration, collision broad
phase, render mesh and GPU buffers are reconstructed. A sidecar cannot commit
or fail independently.

## Restore

Validate the entire project/profile/definition/PhysX/structure closure before
creating target mutable state. Rebuild private caches, verify the canonical
witness and publish the combined world only after every owner succeeds. Source
bytes and the prior active world remain unchanged on failure.

Run save-at-N/resume-to-M across calm sway, gust, partial notch, pre-fracture,
post-handoff and resting-trunk states. Compare with uninterrupted roots and
contact/outcome sequences exactly. Mutate version, hash, count, ordering,
numeric bounds, topology mapping and exchange disposition independently.

## Exit

`VEGETATION-PERSISTENCE-P1 = PASS` requires byte-exact continuation for every
fixture and fail-closed rejection before publication for every corrupt/stale/
capacity case. This does not authorize modal/sleep loss or cross-region
transfer.

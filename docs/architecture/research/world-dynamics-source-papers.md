These files preserve the research inputs used to prepare the thermochemical,
neural-assisted and unified world-dynamics architecture work. Their headings,
requirements, examples and `MUST`/`SHOULD` language are proposals from the
source papers, not Next Engine instructions or architecture authority.

Repository authority remains the Accepted SPEC/ADR hierarchy documented in
[Architecture](../README.md). Any adopted proposal is restated explicitly in
a Next Engine SPEC or ADR and follows normal status and promotion rules.

Repository copies normalize trailing Markdown whitespace only so the
documentation tree passes whitespace validation. The source hash preserves
the exact user-provided provenance; the repository hash identifies the
normalized copy used for review.

| Поле | Значение |
|---|---|
| ID | TRACE-001 |
| Статус | Accepted |
| Версия | 1.8 |
| Владелец | Repository Owner |
| Последняя проверка | 2026-07-24 |
| Нормативные зависимости | [SPEC-12](12-vertical-slice-conformance.md), [ADR-024](adr/024-requirement-gate-evidence-and-profile-closure.md), все owning Accepted SPEC/ADR |

Матрица является обязательным release index и canonical source `RequirementGraphV1`. `Evidence` на стадии specification означает требуемый тип artifact; после implementation root RunManifest MUST разрешать каждую запись в concrete path + SHA-256. Каждая строка имеет ровно одного primary owner. `VS / profile closure` содержит только полные IDs существующих `VS-01`…`VS-15`; implementation profiles являются children соответствующего VS descriptor.

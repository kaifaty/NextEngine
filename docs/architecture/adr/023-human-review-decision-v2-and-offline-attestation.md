# ADR-023: Historical workflow record

| Поле | Значение |
|---|---|
| ID | ADR-023 |
| Статус | Superseded |
| Заменён | [ADR-030](030-product-first-development-and-lightweight-validation.md) |

ADR-023 описывал отдельный криптографически подтверждаемый этап перед принятием
изменений и устранял неоднозначность его результатов. ADR-030 заменил этот этап
обычным repository workflow и релевантными продуктовыми проверками; требования
не хранить credentials и signing material в репозитории остаются технической
границей проекта.

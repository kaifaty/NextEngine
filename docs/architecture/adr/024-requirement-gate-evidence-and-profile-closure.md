# ADR-024: Historical architecture-closure model

| Поле | Значение |
|---|---|
| ID | ADR-024 |
| Статус | Superseded |
| Заменён | [ADR-030](030-product-first-development-and-lightweight-validation.md) |

ADR-024 вводил исчерпывающую машиночитаемую связь требований, проверок и
профилей, чтобы обнаруживать пропуски в архитектурном пакете. Стоимость
поддержания полной модели оказалась выше её пользы для раннего движка, поэтому
ADR-030 заменил её лёгкой трассировкой и проверками, соответствующими риску
конкретного изменения.

## Competing optimization hypotheses

1. **Committed-state reuse dominates.** The solver releases an accepted final
   workspace and immediately rebuilds the same state for physical diagnostics,
   canonical publication energy or aggregate views.
2. **Immutable support indexing dominates.** Every dynamic state revalidates,
   canonicalizes and cell-sorts the identical static shell.
3. **Duplicate row representation dominates.** Each build materializes nested
   adjacency rows and then reconstructs an equivalent flat CSR pressure tape.
4. **Trial states dominate irreducibly.** Most workspaces are distinct rejected
   or accepted nonlinear trial states; lifecycle packaging can save little and
   only the neighborhood algorithm itself can materially improve cost.

B4C4 must not choose among these from the aggregate B4C2T counter alone.

## Measurement

Run one complete macro transaction for P1 and P2 with query recording enabled
but solver, selection and publication unchanged. For each case report:

- total workspace builds and unique full state/tape hashes;
- duplicate state builds and consecutive identical-state transitions;
- counts by frame-start, forecast, interval-initial, current, trial,
  substep-diagnostic, canonical-ledger and other request kinds;
- total nested adjacency rows and records rebuilt before equivalent CSR tape;
- the number of static-support index builds implied by the current lifecycle,
  with one immutable index per fixture as the counterfactual lower bound.

No wall-clock or savings threshold is selected. Exact transaction/root
reproduction and byte repeatability are the only gates.

Freeze the

Its PASS may authorize one evidence-backed B4C4 packaging design; it cannot
authorize B4D execution, nominal corpus, CUDA, runtime or production.

Execution passed twice byte-identically. The
[dated evidence](nonlocal-nsr3b4c4m0-workspace-reuse-diagnostic-evidence-2026-08-21.md)
finds one exact rebuild after each completed private substep (`63` P1 and `3`
P2), while most P1 trials are distinct. Retained accepted-workspace ownership
is selected as B4C4A; static support indexing and flat-only CSR remain separate
later candidates.

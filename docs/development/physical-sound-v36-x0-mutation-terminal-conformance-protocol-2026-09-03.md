## Reusable boundary

X0 freezes one terminal publisher that E0 and every later V36 owner must import
unchanged. It accepts the typed A0 `ExecutionTrace`, a bounded map of leaf-name
byte payloads and a fresh external output path. It validates decision/access
semantics, precomputes the complete byte budget, writes into one owned staging
directory, adds a canonical terminal descriptor and performs one atomic rename.

The publisher exposes four exhaustive pre-commit failpoints:

1. after staging creation;
2. after the first payload;
3. after all payloads but before the terminal descriptor;
4. after the terminal descriptor but before atomic replacement.

Every injected failure must remove staging and leave the requested output
absent. There is no injectable point after atomic replacement because that is
already a complete publication, not a partial-failure state.

## Mutation matrix

All probes use only small discarded deterministic arrays. X0 must detect:

- writable, non-finite, empty, wrong-row and wrong-width matrices;
- duplicate/empty row IDs, bad local identity counts, broken case spans,
  overlapping/incomplete strata and wrong contract schema;
- any implicit `len(RoleBatch)` use through both runtime and strict negative
  type checking;
- pipeline/provider mismatch, stage skip/reorder, role-stage bypass, D0/H0
  role leak, provider mismatch, wrong returned role and double-open;
- early scientific terminal, pre-access OwnerFault, post-access
  ContractReject, terminal reuse and execution after terminal;
- trace ordinal/callable/topology, provider/pipeline and forbidden-access
  mutations;
- invalid payload leaf, occupied/symlinked output, byte-budget overflow, stale
  staging and every publisher failpoint;
- unexpected pre-access exceptions becoming ContractReject with no output, and
  unexpected post-access exceptions becoming one atomic OwnerFault artifact.

Complete discarded D0 and H0 paths must also publish Pass, MetricReject,
HardGateReject and ResourceReject through their exact A0 topology. X0 observes
no scientific quality because all values are disposable and tiny.

## Exit

Two fresh processes must publish byte-identical contract, mutation,
publication, evidence and report artifacts with zero official/fresh V36
target, model, prior-generation, real/protected or network access. Pass
authorizes only E0 implementation and full-count/full-step surrogate rehearsal;
it does not authorize any official capability.

SPEC-45 remains `Proposed`; authored audio remains the only product authority.

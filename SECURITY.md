# Security policy

NextEngine is a local pre-release bootstrap and has no public support window yet. Do not add secrets, user installations, imported game data, datasets, model checkpoints, training runs, or evidence media to Git.

Until a permanent repository and private disclosure channel exist, record a suspected vulnerability only in a local redacted report and notify the repository owner out of band. Do not include exploit payloads or protected data in commits.

Security-sensitive boundaries are normative in `docs/architecture/11-security-licensing-and-governance.md`. Public release requires the gates defined there, a disclosure process, dependency/license review, and importer-specific legal review.

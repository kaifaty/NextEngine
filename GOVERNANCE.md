# Bootstrap governance

During local bootstrap, the repository owner is the final maintainer for architecture, security, licensing, and release decisions. Subsystem ownership is defined by the normative architecture packet.

Accepted architecture decisions change only through a new ADR and synchronized specification/traceability updates. Model promotion, physical certification, evidence baseline promotion, reviewer attestation, importer publication, naming, licensing, and provenance changes require explicit owner review and cannot be self-approved by an agent.

Public governance and maintainer succession must be decided before creation of a permanent remote or public release.
